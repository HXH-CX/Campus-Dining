### 踩到并修掉的三个坑（重点）
1. **改评分后没 flush 就跑重算 SQL** → `dishes.avg_rating` 用旧值，菜品均分与评分记录不一致。

### 本机 GitHub 网络坑（重要，别重复排查）
- Steam++（SteamTools / Watt Toolkit）在加速 GitHub：`hosts` 把 github.com/api.github.com 等
  指向 127.0.0.1，HTTPS 握手拿到的是 `SteamTools Certificate` 签的伪证书。
- 症状：git 和 curl 一律 `schannel: CRYPT_E_NO_REVOCATION_CHECK (0x80092012)`。
- **无效的尝试**：`http.schannelCheckRevoke=false`、换 openssl 后端（报 unable to get local issuer）、
  清空 http_proxy/https_proxy（劫持在系统层，不走环境变量）。
- **有效解法**：SSH over 443。
  - 22 端口被拒；`ssh.github.com:443` 通。
  - `~/.ssh/config` 里把 github.com 映射到 ssh.github.com:443。
  - 密钥 `~/.ssh/id_ed25519`（2026-10-30 生成，无密码短语）。
- 注意：HTTPS 路径下不要把 PAT 交出去——流量会被这个中间人看到。

### 又抓到一个按需引入的坑（重要）
上批的自定义 resolver 把子组件的 sideEffects 全指向父目录，结果 `el-form-item` / `el-tab-pane` /
`el-breadcrumb-item` / `el-dropdown-menu,item` / `el-table-column` / `el-option` 的**样式整个没加载**。
现象很隐蔽：DOM 结构正常、页面"看起来差不多"，只有面包屑末尾多一个斜杠（分隔符的 `:last-child` 隐藏规则丢了）。
根因：子组件**没有独立 JS 入口**（必须从父目录 index 导入），但**样式有独立文件**（theme-chalk/el-*-*.css），
父组件的 style/css 不会带上。
修法：`sideEffects: [父目录/style/css, 自己目录/style/css]`。判断方式：`es/components/<name>/style/css.mjs` 是否存在。
